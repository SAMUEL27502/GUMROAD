# Hormone Decoded — Gumroad profile page

Custom profile landing page for [@hormonedecoder7](https://hormonedecoder7.gumroad.com/).

## Preview & publish

```sh
gumroad pages preview ./landing.html --json --no-input
gumroad pages push profile ./landing.html --json --no-input
```

The page replaces the entire Gumroad profile and links visitors to product pages (no checkout embeds).
